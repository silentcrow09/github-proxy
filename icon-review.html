速度线的存在感偏弱，缩到 16px 基本只剩一个小点。

G猫头标 + 闪电角标

两者兼得：主体是 GitHub 标识，右下角是闪电。32px 以上很清楚，16px 角标会糊。

H几何 G（单线）

单线几何 G，16px 下最清晰。但它是一个字母，不是 GitHub 官方标识。
